# План съёмки: кадр → что есть → что доделать

✅ готово к записи · 🛠 нужно доделать · ⚠️ в списке не так, как устроено на самом деле: нужна замена кадра

Общее: запись 1080p+, шрифт терминала 18–20pt, отдельный чистый демо-проект (`~/demo/babysitter-demo`), секреты только в env.

---

## 1. Установка и настройка

| Кадр | Статус | Что нужно |
| --- | --- | --- |
| `/plugin` → мод в списке | 🛠 | Сейчас мод подгружается как dev-мод (hot reload). Переношу его в проект и ставлю через локальный marketplace (`/plugin install babysitter@local`), тогда он виден как обычный плагин |
| `/plugin configure` → пороги | ✅ / 🛠 | Пороги уже есть: повторы ошибки (`loopRepeats`), серия ошибок, минуты простоя, лимит вызовов и минут, режим, перезапуски, Haiku, пуш. **Лимита токенов нет**, добавляю `tokenBudget` |
| Папка мода: манифест, хуки, медленный скролл | 🛠 | После переноса в проект: `.claude-plugin/plugin.json` → `hooks/register.tsx` → `detectors.ts` → `interventions.ts` → `report.ts` |

## 2. Запуск агентов

| Кадр | Статус | Что нужно |
| --- | --- | --- |
| Запуск 4 фоновых агентов с задачами | ✅ | Один подготовленный промпт в основную сессию: «запусти 4 фоновых агента: …». Мод ловит их через хук `agent.spawn`, этот код показать отдельно |
| Список агентов со статусами | ✅ | Панель `/babysit` (статусы 🟢🟡🟠✅🔴) плюс встроенный список задач Claude Code |
| 4 терминала 2×2, в каждом свой агент | ⚠️ | Сабагенты живут **внутри одной сессии**, мод следит за агентами своей сессии. **Замена:** сплит 2×2 = основной транскрипт · панель `/babysit` · транскрипт агента №3 · `/cost`. Или 4 отдельные сессии, но тогда это 4 независимые «няни» и 4 отчёта |

## 3. Агент застрял

| Кадр | Статус | Что нужно |
| --- | --- | --- |
| Транскрипт агента №3: тот же вызов, та же ошибка, ≥3 раза | 🛠 | Демо-репо с ловушкой: flaky-тест, который правкой кода не чинится. `loopRepeats = 3`, поэтому в кадре будет ровно 3 повтора |
| Растущие токены и деньги | ✅ | `/cost` и строка статуса мода. Можно добавить токены в строку статуса |
| Агент висит на permission prompt | ⚠️ | В auto mode промптов нет. В режиме default фоновый агент может ждать разрешения: мод видит это как зависший вызов (детектор stall, ждёт 3× порога). Для кадра: `stallSeconds = 40`. Отдельного детектора «ждёт разрешения» нет |

## 4. Срабатывание мода

| Кадр | Статус | Что нужно |
| --- | --- | --- |
| Строка «stuck, killing» в выводе | 🛠 | Сейчас есть только тосты и панель. Добавляю строку в транскрипт на каждое действие: `🍼 #3 Fix flaky test · loop: npm test ×3, та же ошибка → correcting / killing / respawning` |
| №3 переходит в killed | ✅ | Ступень «kill» уже есть. Нужно, чтобы №3 не исправился после подсказки: это обеспечивает ловушка. Перезапуск в auto mode блокируется, поэтому для записи нужен режим default или разрешение на `Agent` |
| Вызов судьи: какие события ушли и ответ «no progress» | 🛠 | Сейчас Haiku только ставит диагноз. Делаю **судью**: перед вмешательством Haiku получает последние события и отвечает `VERDICT: NO_PROGRESS / PROGRESS` с причиной; мод действует только на NO_PROGRESS. Промпт и вердикт пишутся в `.babysitter/judge/…md`, `/babysit judge` показывает последний крупно |

## 5. Rogue-момент

| Кадр | Статус | Что нужно |
| --- | --- | --- |
| Агент пытается `rm` тест, править файл вне задачи, `git push` | 🛠 | Это **guard**, которого в 0.1 нет. Делаю: хук `tool.call` у сабагентов → `git push`, удаление тестов, запись вне папки проекта либо отказ хука, либо подтверждение через диалог мода |
| Агент реально так делает | ⚠️ | Гарантировать нельзя. Задача «сделай CI зелёным» иногда приводит к удалению теста, но не всегда, так что может понадобиться несколько дублей. Если агенту прямо сказать удалить тест, это постановка, и в кадре это надо так и назвать |

## 6. Отчёт

| Кадр | Статус | Что нужно |
| --- | --- | --- |
| Дайджест в терминале | ✅ | Отчёт приходит notice в транскрипт и файлом `.babysitter/reports/` (файл проверить на живом прогоне) |
| Тот же отчёт в Telegram / Slack | 🛠 | Сейчас уходит пуш в приложение Claude. **Telegram:** через Bot API, токен бота вы вводите сами в `/plugin configure` (поле секретное). **Slack:** коннектор не авторизован |
| `/cost` в конце ночного прогона | ✅ | Только если прогон действительно идёт ночь: пороги «ночные», задачи длинные |

## 7. Провал первой версии

| Кадр | Статус | Что нужно |
| --- | --- | --- |
| `git checkout` старого коммита и спам алертов | ⚠️ / 🛠 | Сейчас нет ни git-истории, ни «спамящей» версии. **Честный путь:** коммит v1 = только правила, без судьи. Гоняем её на демо по-настоящему и пишем, что она флагает зря (долгий `npm install` как stall, законные повторы). Потом коммит v2 с судьёй. Подделывать спам не надо |
| `git diff` v1 → v2, где добавлен судья | 🛠 | Появится после двух коммитов выше |
